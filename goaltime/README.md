# ⚽ GoalTime — منصة حجز ملاعب كرة القدم

منصة ويب متكاملة (Multi-Vendor) تجمع أصحاب الملاعب باللاعبين: بحث وفلترة، حجز فوري بجدول أوقات تفاعلي، تقييمات حقيقية، ولوحات تحكم لأصحاب الملاعب وللإدارة — بثلاث لغات (العربية، الإنجليزية، التركية) مع دعم كامل لاتجاهي RTL وLTR.

## ▶️ التشغيل

لا يحتاج أي تثبيت أو بناء — افتح `goaltime/index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
cd goaltime
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

يصلح للنشر المباشر على GitHub Pages أو Netlify أو أي استضافة ثابتة.

## 👤 الحسابات التجريبية

من زر «تسجيل الدخول» اختر أحد الحسابات الجاهزة:

| الدور | ماذا يرى |
|---|---|
| ⚽ لاعب | البحث، الحجز، حجوزاتي، التقييم |
| 🏟️ صاحب ملعب | تقويم الحجوزات، الأسعار، تأكيد الحضور/الغياب |
| 👑 مدير المنصة | الإحصائيات، اعتماد الملاعب، حظر المستخدمين |

أي رقم جوال جديد يُنشئ حساب لاعب تلقائياً.

## ✨ الميزات المنفذة

- **ثلاث لغات** مع تبديل فوري للاتجاه (RTL/LTR) وملفات ترجمة مركزية في `js/i18n.js`.
- **بحث وفلترة**: المدينة، السعر، التقييم، توفر التاريخ، ونص حر.
- **صفحة الملعب**: معرض صور، مرافق بأيقونات، خريطة جوجل مدمجة، تقييمات.
- **محرك الحجز**: جدول ساعات تفاعلي (أخضر متاح / أحمر محجوز)، أسعار ذروة (8م–12م) وويكند (جمعة/سبت)، دفع كاش عند الوصول.
- **واتساب**: زر يرسل تفاصيل الحجز + رابط الموقع الجغرافي برسالة جاهزة.
- **سياسة الإلغاء**: مهلة قابلة للضبط لكل ملعب (افتراضي 6 ساعات).
- **حماية من الحجوزات الوهمية**: صاحب الملعب يؤكد الحضور بعد كل مباراة؛ تكرار الغياب (حد يحدده صاحب الملعب) يحظر الحساب تلقائياً.
- **تقييمات موثوقة**: لا يقيّم إلا من أكمل حجزاً فعلياً في الملعب.
- **لوحة صاحب الملعب**: تقويم يومي، تعديل الأسعار والصور وسياسات الإلغاء.
- **لوحة الإدارة**: مؤشرات (إجمالي الحجوزات، نسبة الإلغاء…)، الملاعب الأكثر طلباً، أوقات الذروة، اعتماد الملاعب الجديدة، حظر/رفع حظر.

## 🏗️ البنية والتوسع المستقبلي

```
goaltime/
├── index.html            هيكل الصفحة الواحدة (SPA)
├── css/style.css         نظام التصميم (Mobile-First، خصائص CSS منطقية للـ RTL)
└── js/
    ├── i18n.js           الترجمات الثلاث + التواريخ والأوقات المحلية
    ├── store.js          طبقة البيانات ومحرك الحجوزات (localStorage)
    ├── app.js            التوجيه، شريط التنقل، تسجيل الدخول، التنبيهات
    ├── views-customer.js واجهات اللاعب
    ├── views-vendor.js   لوحة صاحب الملعب
    └── views-admin.js    لوحة الإدارة
```

كل دوال `store.js` مصممة لتطابق نقاط نهاية (Endpoints) في Backend حقيقي — عند الانتقال إلى Supabase أو Laravel أو Node.js يُستبدل محتوى الدوال فقط دون تغيير الواجهات. إرسال واتساب يتم حالياً عبر روابط `wa.me`؛ عند توفر Backend يُستبدل بـ WhatsApp Business API ليصبح الإرسال آلياً بالكامل. بوابات الدفع الإلكتروني تُضاف لاحقاً في خطوة تأكيد الحجز (`createBooking`).

البيانات التجريبية تُحفظ في متصفحك (localStorage) — لإعادة الضبط امسح بيانات الموقع من المتصفح.
